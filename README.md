## General Repository rules
```
- Please dont push or edit anything directly in the main branch.
- Any development purposes should be done in its own branch based on the dev branch.
- Any bug-fix or issue work or new feature Implementation has to have its own issue created first
and then its own branch based on dev ofcourse.
- The 'dev' are allowed to be merged in main but only through pull requests.
- Dont change anything directly in the 'dev' branch.
- No license are allowed to be added unless spoken to owner first.

```
---

## General issue rules
```
- Any issue created has to be named in the following order:
  [Issue Type] #001 | Issue Name
  description needs also to be added to know what really its about.
- If a issue is a bug, feature or enchancment then please create the branch for it directly in the github page.
- A issue must have labels that represent its purpose.
- No duplicate issues allowed.

```
---

## General branches rules

```
- A branch must created based on dev and according to the issue.
- Once you make your first commit please create a pull request for the current branch.
- Branch merging are only done using pull requests.
- Branch name must be the same as the issue being workes on.

```
